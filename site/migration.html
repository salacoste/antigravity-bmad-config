Migrate from v1 to v2

Antigravity sunset workflows on 2026-10-19, and BMad 6 dropped .bmad-core — the two things the v1 stack stood on. Here is the documented path off the dead stack.

What died, and when

Two upstream decisions landed on the same template.

Net effect: a January-era clone of this template carries dead /pm-style commands and a stale runtime. The fix is three steps.

Three steps to v2

Steps 1 and 2 follow upstream guides; step 3 is copy-paste. In order, they take a January clone to a pinned v2 install.

  1. 1

    Antigravity side: workflows → skills

    Follow the official Workflows → skills migration guide. Skills are the replacement surface — this template now ships skills plus a plugin, not workflows.

  2. 2

    BMad side: v4 .bmad-core → v6 _bmad/

    Upgrade with the v6 installer: it detects v4 leftovers and offers to back them up, and your planning docs move to _bmad-output/planning-artifacts/. The upstream upgrade-to-v6 guide has the details.

  3. 3

    Delete v1 leftovers

    Everything below is v1 residue; none of it runs on v2. One caveat: the AGENTS.md in this list is the v1-generated one — the current repo ships its own. On a fresh clone, none of these paths exist.

    .agent/workflows/       # dead since the 2026-10-19 sunset
.bmad-core/             # BMad 4.44.3 runtime; v6 installs into _bmad/
.claude/commands/BMad/  # transposed Claude slash commands
.cursor/rules/bmad/     # transposed Cursor rules
.gemini/commands/BMad/  # transposed Gemini commands
transpose_bmad.py       # the v1 transposition script
AGENTS.md               # v1-generated; the current repo ships its own

Your planning artifacts are not lost

Migration replaces machinery, not your work.

Docs move, they don’t vanish

Old planning docs don’t die with .bmad-core — they move to _bmad-output/planning-artifacts/. The PRD, architecture, epics, and stories keep working as BMad state.

Nothing is silently deleted

The v6 installer offers to back up v4 leftovers before replacing them. And the rm -rf in step 3 deletes exactly the paths listed above it — no more.

Still need v1?

History is preserved, not rewritten.
