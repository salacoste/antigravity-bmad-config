# Contributing

Thanks for helping improve this template.

## What this repo is

A thin layer over a **pinned** BMAD Method install (version lives in
`.bmad-version`): setup script, team-layer presets (`presets/`), and an
Antigravity plugin (`.agents/plugins/antigravity-bmad/` — orchestrator
skill + rules). The BMAD runtime itself (`_bmad/`, `.agent/skills/`,
`.agents/skills/`) is generated by `./setup.sh` and never committed.

## Ground rules

- Generated dirs are read-only for contributors: `_bmad/`, `_bmad-output/`,
  `.agent/`, `.agents/skills/`.
- Preset changes go in `presets/**` (the source), not `_bmad/custom/`
  (the applied output).
- The version pin changes only together with a passing `make smoke-test`.
- Don't reference v6 shim skill names (`bmad-create-story`,
  `bmad-dev-story`, …) — they are removed in BMAD v7.

## Typical contributions

- Preset improvements (new languages, persona overrides) — start from
  `presets/english/`, see `presets/README.md`.
- Orchestrator skill and rules refinements
  (`.agents/plugins/antigravity-bmad/`), following the
  [Antigravity plugin format](https://antigravity.google/docs/plugins/).
- Setup/CI robustness (`setup.sh`, `scripts/smoke-test.sh`,
  `.github/workflows/ci.yml`).
- Doc accuracy (README.md / README_RU.md / AGENTS.md).

## Before opening a PR

```bash
make smoke-test   # must pass
make verify-pin   # pinned version must resolve on npm
```

Keep changes focused; update both READMEs when behavior changes.
