From clone to first BMad session

Three commands and one Antigravity window. Every command on this page is exactly what the repository runs.

Before you start

Any surface works: the 2.0 app, the IDE extension, or the agy CLI.

The hard requirement — setup.sh exits with an error on anything older.

Optional: without it BMad installs, but bmad-build / bmad-build-auto will halt — setup.sh warns, it doesn't fail.

Four steps to a working install

  1. Clone the template and reset git

    You get the whole template under my-project, with a fresh git history that starts with you.

  2. Run setup

    Installs bmad-method@6.12.4 — modules bmm, tools antigravity and antigravity-cli — and applies the preset to _bmad/custom/. It's idempotent: safe to re-run any time to restore or update.

  3. Open the folder in Antigravity

    App, IDE extension, or agy — any surface. The plugin in .agents/plugins/antigravity-bmad/ loads automatically once the folder is open.

  4. Start the loop

    Run /bmad-orchestrate — the template's entry point — or /bmad-help for upstream orientation. Planning artifacts land in _bmad-output/.

What got installed

After a clean setup, my-project/ looks like this:

my-project/
├─ _bmad/                         ← pinned BMad runtime (6.12.4)
│  └─ custom/                     ← team layer: presets land here
├─ .agent/skills/                 ← 29 BMad skills (app target)
├─ .agents/skills/                ← 29 BMad skills (CLI target)
│  └─ plugins/antigravity-bmad/   ← orchestrator plugin
└─ _bmad-output/                  ← your planning artifacts

When something goes sideways

Node too old 

setup.sh prints ERROR: Node >= 20.12 required (found: vX.Y.Z) and exits. Upgrade Node — nvm install 20 works — then re-run ./setup.sh.

uv not found 

A warning, not a failure: uv not found — BMAD installs, but bmad-build / bmad-build-auto will halt. Install uv with Python 3.11+ from docs.astral.sh/uv — no re-setup needed.

command not found: /bmad-orchestrate 

The plugin lives in .agents/plugins/antigravity-bmad/ and loads when the project folder is opened in Antigravity. Reopen the folder — or restart the window — and check that plugins are enabled: Antigravity plugin docs.
