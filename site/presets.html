Presets that survive updates

Presets write to _bmad/custom/ — the one BMad-owned directory the installer never touches. Apply one with a single command, and it outlives every BMad update.

The team layer: _bmad/custom/

Every BMad install reserves one directory for your team. The installer regenerates everything around it on update — and never writes inside it.

Never touched by the installer

_bmad/custom/ is the one BMad-owned directory the installer never touches — safe across updates, as documented in the BMad v6 config header (_bmad/config.toml).

Re-applied on every setup

./setup.sh re-installs the pinned runtime — regenerating _bmad/ — and then applies your preset into _bmad/custom/, so a BMad update never eats your team's configuration. Presets are idempotent: re-running setup re-applies them, and if you have local modifications in _bmad/custom/, setup asks before overwriting.

Merges are predictable

Presets carry per-skill persona overrides in _bmad/custom/<skill-name>.toml. Merge rules are documented in each skill's customize.toml: scalars replace, arrays append.
